# GoldenEye 007 Remastered — Protótipo não oficial

Protótipo experimental de FPS para navegador baseado no GDD fornecido. Inclui as missões Dam, Facility e Runway em Three.js, com controles de mouse/teclado e suporte inicial a gamepad.

## Como executar

Abra o `index.html` usando um servidor HTTP estático (ou configure GitHub Pages com a raiz `/` da branch `main`). É necessária conexão à internet para carregar Three.js, Tailwind CSS e fontes externas.

## Direitos

Projeto de estudo e prototipagem **não oficial**. GoldenEye 007, James Bond e elementos relacionados pertencem aos titulares dos respectivos direitos. O código aqui fornecido não concede direitos de comercialização ou redistribuição de materiais protegidos.

## Estado

Três missões prototipadas; a campanha completa de 20 fases descrita no GDD ainda não está implementada.
